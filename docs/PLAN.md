# План развития NeoTD

Направление выбрано по 20 вопросам, а сами вопросы опираются на разбор отзывов и дизайна TD в [RESEARCH.md](RESEARCH.md).

## Решения

| Тема | Решение |
| --- | --- |
| Темп | Бонус за досрочный запуск следующей волны. Ускорение ×2/×3 уже есть. |
| Превью волны | Полное: типы, броня, скорость, количество. |
| Прокачка | Ветки специализации на третьем уровне. |
| Синергии | Не добавляем в первой части — держим читаемую математику. |
| Мета | Новые протоколы и модификаторы, без обязательных усилений. |
| Roguelite | Отдельный режим с модификаторами волн и наградами. |
| После 15 волн | Бесконечный режим с ростом сложности и таблицей рекордов. |
| Карты | 3 арены с разными входами и ограничениями. |
| Враги | Щит/регенерация, летающие, делящиеся, невидимые. |
| Боссы | Уникальные механики каждому. |
| Герой | Не нужен — остаёмся чистым TD. |
| Мультиплеер | Не в первой части. Кооп — в NeoTD II. |
| Экономика | DATA за убийства и зачистку волны. |
| Сложность | Три уровня: спокойный, стандартный, хардкор. |
| Камера | Свободная орбита плюс кнопка вида сверху. |
| QoL | Перемещение башни, отмена действия, приоритеты целей, массовые действия. |
| Визуал | Усилить терминал и глитч в текущей палитре. |
| Аудио | Музыка и слои: эмбиент, нарастание к волнам. |
| Платформы | Веб, .exe для Windows, AppImage для Linux. |
| Репозиторий | Приватный. |

## Сделано в 0.2

- Превью волны с HP, скоростью, бронёй и тегами угроз.
- Четыре ветки апгрейдов по две специализации на протокол.
- Бонус за досрочный запуск с таймером и наградой.
- Перенос башни без потерь, отмена действия, приоритеты целей, массовое улучшение и продажа.
- Вид сверху по кнопке и клавише.
- Три арены: SECTOR 07, CROSSFIRE, THE WELL.
- Три сложности с разным бюджетом и прочностью врагов.
- Четыре новых врага: BULWARK, WISP, MITOSIS, PHANTOM.
- Механика босса: щит, ярость, свита.
- Бесконечный режим и ROGUE с модификаторами волн и выбором наград.
- Музыкальный слой, реагирующий на фазу боя.
- Desktop-сборка: portable .exe и workflow для Windows/Linux.

## Осталось

### 0.3 Мета и контент

1. Мета-прогрессия: новые протоколы за забеги, а не обязательные усиления.
2. Больше модификаторов волн и наград ROGUE.
3. Ещё одна-две арены с двумя входами.
4. Достижения и таблица рекордов для бесконечного режима.

### 0.4 Подача

1. Усиление терминальной эстетики: больше сигнальных анимаций и глитча.
2. Отдельные акценты для боссов и редких событий.

## Чего не делаем в первой части

- Синергии башен.
- Управляемый герой.
- Мультиплеер — переносится в NeoTD II.

## Проверка после каждой правки

1. Как часто игрок принимает осмысленное решение?
2. Понимает ли он, почему пропустил врага?
3. Меняет ли он стратегию от волны к волне?
