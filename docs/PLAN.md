# План развития NeoTD

Направление выбрано по 20 вопросам, а сами вопросы опираются на разбор отзывов и дизайна TD в [RESEARCH.md](RESEARCH.md).

## Решения

| Тема | Решение |
| --- | --- |
| Темп | Бонус за досрочный запуск следующей волны. Ускорение ×2/×3 уже есть. |
| Превью волны | Полное: типы, броня, скорость, количество. |
| Прокачка | Ветки специализации на третьем уровне вместо равномерного роста. |
| Синергии | Не добавляем в первой части — держим читаемую математику. |
| Мета | Новые протоколы и модификаторы, без обязательных усилений. |
| Roguelite | Отдельный режим со случайными наградами и модификаторами волн. |
| После 15 волн | Бесконечный режим с ростом сложности и таблицей рекордов. |
| Карты | 3–4 арены с разными входами и ограничениями. |
| Враги | Все четыре: щит/регенерация, летающие, делящиеся, невидимые. |
| Боссы | Уникальные механики каждому, а не только больше HP. |
| Герой | Не нужен — остаёмся чистым TD. |
| Мультиплеер | Не в первой части. Кооп — в NeoTD II. |
| Экономика | DATA за убийства и зачистку волны, без второго ресурса. |
| Сложность | Три уровня: спокойный, стандартный, хардкор. |
| Камера | Свободная орбита плюс кнопка вида сверху. |
| QoL | Перемещение башни, отмена действия, приоритеты целей, массовые действия. |
| Визуал | Усилить терминал и глитч в текущей палитре. |
| Аудио | Музыка и слои: эмбиент, нарастание к волнам, акценты боссов. |
| Платформы | Веб остаётся, цель — .exe для Windows и Linux. |
| Репозиторий | Приватный. GitHub Pages не включаем. |

## Порядок работ

### M1. Читаемость и контроль

1. Превью следующей волны: состав, броня, скорость, количество.
2. Ветки специализации башен на третьем уровне.
3. Бонус за досрочный запуск волны.
4. QoL: перемещение башни с полным возвратом, отмена действия, приоритеты целей, массовые действия.
5. Камера: кнопка вида сверху.

### M2. Разнообразие угроз

1. Новые враги: щит/регенерация, летающие, делящиеся, невидимые.
2. Уникальные механики боссов.
3. Три уровня сложности.
4. 3–4 арены с разными входами.

### M3. Причины вернуться

1. Бесконечный режим и таблица рекордов.
2. Roguelite-режим.
3. Мета: новые протоколы и модификаторы.

### M4. Подача

1. Музыка и слои звука.
2. Усиление терминальной эстетики.

### M5. Desktop

Сборка под Windows и Linux (.exe / AppImage) — после того как геймплей устоится.

## Чего не делаем

- Синергии башен — сознательно оставляем простую математику.
- Управляемый герой — превращает TD в экшен.
- Мультиплеер в первой части — переносим в NeoTD II.

## Проверка после каждой правки

1. Как часто игрок принимает осмысленное решение?
2. Понимает ли он, почему пропустил врага?
3. Меняет ли он стратегию от волны к волне?
