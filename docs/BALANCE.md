# Баланс NeoTD — отчёт симулятора

Сгенерировано `npm run balance`. Безголовый симулятор играет кампанию на всех аренах и сложностях пятью стратегиями по 30 прогонов на сочетание (2250 забегов).

Модель: реальные волны, HP-скейл, броня, щиты, деление, полёт, замедление, сплэш, ветки третьего уровня, экономика и бонус зачистки. Размещение башен — жадное по покрытию маршрута. Игрок не идеален: симулятор не переносит башни и не подбирает приоритеты целей.

Колонки: **WIN** — доля побед, **WAVE** — средняя достигнутая волна, **CORE** — средняя целостность, **TOWERS** — башен к концу, **KILLS** — уничтожено.

## Как читать

- WIN ниже 20% на «Спокойном» — арена или экономика слишком жёсткие для новичка.
- WIN выше 80% на «Хардкоре» — не хватает давления, стоит поднять HP или плотность волн.
- Разброс между стратегиями больше 40 п.п. означает, что один протокол доминирует.
- Средняя волна ниже 10 при нулевых победах — провал в середине кампании, а не в финале.

Отчёт пересобирается командой `npm run balance`; цифры зависят от сида, поэтому при правках баланса сравнивай относительные изменения, а не абсолютные проценты.
